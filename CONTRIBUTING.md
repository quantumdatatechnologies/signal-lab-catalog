# Contributing

Thanks for helping keep the catalog useful and accurate.

- **Suggest a free data source:** open a "Suggest a dataset" issue, or use the `suggest_source` tool on the MCP server, or email signal-lab@qdt.ai. Please include the provider URL, the licence or terms link, and whether a key or sign-up is needed.
- **Report a problem with an entry** (broken link, wrong licence, outdated limits): open a "Report a dataset problem" issue with the entry `id`, or email signal-lab@qdt.ai.
- **Code fixes** (examples, `scripts/refresh.py`): pull requests are welcome. Keep scripts standard-library only and run the examples against the live server before submitting.
- **Do not edit `data/` by hand.** It is regenerated daily from the public MCP server. Corrections to catalog content are made at the source after review.

Entries are reviewed before they are listed; we only list sources whose terms we have read. We do not accept sponsored or paid placements.

By contributing code you agree it is released under the MIT licence.
