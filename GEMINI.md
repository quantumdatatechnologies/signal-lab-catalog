# Signal Lab

Signal Lab is a growing catalog of free data sources, updated daily. The `signal-lab` MCP server needs no API key or sign-in.

Use it when the user needs a free API or dataset (finance, macro, research, government and more): search the catalog, check what access a source needs (free, free signup), and cite the source link returned by the tool. Report only what the tools return; do not guess counts or availability.

Docs: https://signal-lab.qdt.ai
