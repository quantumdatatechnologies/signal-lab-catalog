# Examples

Both examples call the public MCP server (`https://signal-lab.qdt.ai/api/mcp`, no key): list tools, search the catalog, get one entry.

- Python (standard library only): `python3 examples/python/mcp_example.py`
- TypeScript (Node 18+; Node 22.6+ can run it directly, or use `npx tsx`): `node examples/typescript/mcp-example.ts`
